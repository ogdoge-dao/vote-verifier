# Security

If you find a way to make the verifier report `PASS` for a package that does not match the votes and
fingerprints recorded on Solana, or any other security problem, please report it privately:
**Security → Report a vulnerability** on this repository.

Please do not open a public issue for security problems.

The OGDOGE DAO team will never ask for your seed phrase or private key, ask you to connect a wallet to run
this script, or send you a different download link by DM. Only download the verifier from this repository.
